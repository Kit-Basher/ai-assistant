# Personal Agent v0.2.8 Release Notes

v0.2.8 is the final Work Package 1 promotion candidate. It includes all v0.2.7
unified-routing work and closes a live-only semantic payload issue found during
post-promotion verification.

## Live verification correction

- Absolute and relative filesystem paths are now treated as typed capability
  inputs rather than semantic intent words. Directory names and path depth can
  no longer dilute or redirect list/search/read selection.
- A hyphenated or dotted name inside a syntactically local path can no longer
  be intercepted by the public-entity/web boundary before capability routing.
- Filesystem action-family exclusion uses the same general edit/transposition
  matcher as selection, so a misspelled search action cannot also acquire the
  directory-list boost.
- The generic response guard detects the semantic family of blanket file or
  directory-access denials while preserving honest configured-root and
  permission restrictions.
- Production `/chat` regressions cover deep paths whose components resemble
  other capability domains, and the false-runtime-claim suite covers a generic
  model's directory-access denial wording.

All other architecture, registry ownership, safety boundaries, and deferred
Work Package 2 scope remain as documented in the v0.2.7 notes and the Work
Package 1 architecture note.
