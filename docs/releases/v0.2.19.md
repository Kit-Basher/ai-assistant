# Personal Agent v0.2.19

This is the final Work Package 4.5 candidate and supersedes the intermediate
v0.2.17 and v0.2.18 candidates.

In addition to their model-truth, evaluation, Scout/Manager, latency, and
human-spaced identity work, this release closes a final live reconciliation
finding: a compatibility inventory's synthesized `routable=false` default can
no longer override current physical observation and benchmark evidence for an
installed local chat model. Actual benchmark/provider failure still fails the
model closed and remains visible with its precise reason.

No model was downloaded, deleted, or switched. The default remains
`ollama:Gemma:latest` unless the user separately confirms the exact
evidence-backed recommendation.
