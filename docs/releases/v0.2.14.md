# v0.2.14 — Durable Terminal Task Inquiry

This release retains the complete v0.2.13 bounded plan–act–verify task loop and
corrects the final conversational task-control gap found during live WP3
verification.

An explicit task status, plan, or progress inquiry now resolves the most recent
task bound to the same actor and thread even after that task reaches a terminal
state. The lookup is read-only: it cannot reactivate, resume, or advance the
task, and non-status controls still require an active task. This makes verified
final and partial evidence available through ordinary chat as well as the
actor-bound task API and Web UI.

All v0.2.13 action authority, approval, persistence, verification, recovery,
and explicit WP4/WP5 exclusions remain unchanged.
