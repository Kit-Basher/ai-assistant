# Personal Agent v0.2.20

This is the final Work Package 4.5 candidate and supersedes the intermediate
v0.2.17 through v0.2.19 candidates.

It preserves all prior model-truth, evaluation, Scout/Manager, latency,
canonical identity, and routability reconciliation work. It also closes the
last live mutation-semantics findings: `test ... do not change my default` is a
bounded model test rather than a default-change preview, and an explicit
combined denial such as `no, cancel that model change` deterministically clears
an exact pending preview. Negation is interpreted structurally; no model-name
or request-sentence trigger table was added.

No model was downloaded, deleted, or switched. The default remains
`ollama:Gemma:latest` unless the user separately confirms the exact
evidence-backed recommendation.
