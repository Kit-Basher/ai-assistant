# Personal Agent v0.2.17

Work Package 4.5 reconciles installed-model truth and closes deterministic
response pacing before WP5.

- Physical Ollama observations, configured registry rows, remote candidates,
  Scout advice, and Manager history are separate evidence classes.
- `/models`, `/llm/models/truth`, chat inventory, and the Web UI use the same
  canonical observation. Provider timeouts produce unknown/stale—not absent.
- Eight installed chat models were evaluated sequentially through the production
  adapter; the embedding model was objectively excluded. Results and the
  recommendation are advisory and tied to the running build at display time.
- No model was installed, deleted, or selected. A model change still requires
  the exact existing preview/confirmation boundary.
- Ordinary deterministic chat no longer performs readiness probes in its
  front-door predicate. Warm presence and runtime status have release-blocking
  body-complete budgets.

WP5 remote pack acquisition and assistant-created packs remain excluded.
