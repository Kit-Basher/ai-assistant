# Personal Agent v0.2.22

Status: superseded before final WP5 closure. The exact build passed pre-promotion
gates, but a post-promotion read-only check found that an update question with
zero external packs returned HTTP 400 instead of a grounded empty-state answer.
No pack or other user state was mutated. v0.2.23 contains the corrected and
retested behavior.

This Work Package 5 closure release turns the remaining pack-management claims
into production-path behavior and stronger exact-candidate proof.

- Natural chat can inspect, approve, grant, enable, disable, activate, revoke,
  compare, update-check, roll back, and remove an exact dynamic pack version.
  Every mutation remains a single exact, expiring, actor/session/thread-bound
  lifecycle plan; unrelated conversation cannot advance it.
- The Skills UI now searches configured metadata catalogs, shows bounded source
  age/staleness, and exposes an exact rollback preview alongside the existing
  fetch, draft, review, grant, enable, revoke, and remove controls.
- Quarantine fetch results include a bounded dynamic-record identity needed for
  the next review gate, without paths or hostile content.
- The isolated candidate runner now proves workflows A–F through the temporary
  API and mobile/reduced-motion browser UI, including real immutable GitHub
  acquisition, local-data persistence/revocation, visualizer rendering,
  assistant creation, staged update/rollback, and mixed WP3 composition.

No model, Safe Mode, remote fallback, installed model artifact, or live external
pack state is changed by this release. No arbitrary code, shell, broad file or
network authority, automatic lifecycle transition, or model mutation was added.
