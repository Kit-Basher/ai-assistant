# Personal Agent v0.2.28

WP6 pre-reinstall candidate superseding v0.2.27.

- Retains the v0.2.27 resource-observation and Model Scout routing fixes.
- Hardens installed-browser recovery proof to accept truthful ready/healthy
  status language, wait boundedly for the UI busy-state transition, and scope
  the expected HTTP 400 console entry to its one deliberately hostile request.
- Other console errors, network failures, disabled composers, unsafe rendering,
  and unready recovery remain release failures.
- Physical Ubuntu 24.04 fresh-install recovery remains deliberately unproved;
  this release may only be reported as the WP6 pre-reinstall gate.
