# Personal Agent v0.2.24

Superseded by v0.2.25. The v0.2.24 live smoke exposed an indirect
new-model investigation that fell through to generic chat; no state mutation
or data loss occurred. The follow-up release closes that semantic route and
repeats the complete candidate and live gates.

Status: WP6 pre-reinstall candidate. This is not formal WP6 completion until
the user-approved physical Ubuntu 24.04 recovery journey is performed.

## Changes

- Adds a commit/diff-bound layered release proof with automatic native/dynamic
  capability reconciliation, separate blind-language evidence, 25 required
  user journeys, and 16 canonical-gate sensitivity cases.
- Extends the normal UI diagnostics action to export one bounded runtime,
  capability, model, pack, policy, and dependency document while excluding
  secrets, conversations, private files, prompts, and imported pack content.
- Replaces shell-required public onboarding recovery instructions with Setup,
  Diagnostics, and chat actions. Operator CLI commands remain available in
  advanced documentation.
- Introduces the allowlisted `personal-agent.portable-backup.v2` contract with
  atomic creation, member/hash/size/type validation, staged conflict-safe
  isolated restore, corruption/version refusal, idempotent replay, and explicit
  secret re-entry on a new host. The existing confirmation-gated chat backup
  action now emits this verified archive alongside its bounded Backup v1
  authorization evidence, and chat can validate the archive read-only.
- Adds Ubuntu 24.04 preflight and the human physical recovery runbook without
  crossing the destructive OS-install boundary.
- Upgrades the Web UI build toolchain to Vite 8 and the compatible React plugin;
  the prior high/moderate Vite/esbuild advisory chain is absent from the final
  dependency audit.
- Reconciles current pack acquisition/broker, backup, release, and project-state
  claims with the demonstrated WP5/WP6 runtime.

## Preserved boundaries

No capability, pack, model, service, state root, fallback, or approval boundary
is broadened. Promotion must preserve `ollama:qwen2.5:3b-instruct`, Safe Mode,
disabled remote fallback, and zero live external/reference packs.
