# v0.2.11 — Native Capability Inventory and Proof

This release makes the live capability registry and protected inventory the
auditable description of Personal Agent's native product surface.

Highlights:

- 22 native user-goal capabilities with health, self-test, verification,
  policy, and proof contracts;
- bidirectional API/CLI/UI/Telegram/native-skill/compatibility mappings;
- registry-driven, release-blocking proof reports;
- normal-user and advanced capability status API/UI;
- direct natural-chat routing for bounded shell, directory/package previews,
  memory/pack lifecycle, optional search/Telegram, and operator lifecycle;
- concept-level handling of possessive subjects, typed path arguments, and
  container/resource language found during final live validation;
- live optional-provider health reconciliation without adding a dependency
  probe to each ordinary chat message;
- reconciled local-only text-pack ingress claims;
- retained WP1 routing and safety behavior.

This release does not add executable packs, automatic pack acquisition,
managed-service installation, or the general multi-step task loop.
