# v0.2.12 — Bounded Plan–Act–Verify Tasks

This release adds a durable general task loop above the 22-capability native
registry proven in v0.2.11.

Highlights:

- strict `personal-agent.plan.v1`, `personal-agent.task.v1`, and
  `personal-agent.missing-capability.v1` contracts;
- bounded deterministic decomposition and at most one configured-model planning
  generation per plan version for unresolved substantial goals;
- registry-only typed step invocation, exact plan-bound mutation approval, and
  independent evidence-based verification;
- durable canonical-SQLite task/step/event/approval state with restart
  reconciliation, replay protection, concurrency bounds, and terminal retention;
- honest partial, blocked, denied, cancelled, failed, expired, and indeterminate
  outcomes without fabricated completion claims;
- natural chat status/control plus actor/session/thread-bound `/tasks` APIs;
- responsive accessible Web UI task cards that survive refresh;
- registry-driven WP3 proof, invariant/adversarial coverage, and 16-category
  production-path scenario enforcement in main and extended release gates.

This release does not add executable or declarative pack workers, automatic
pack discovery/acquisition/installation, assistant-created packs/tools, or the
WP4/WP5 reference packs.
