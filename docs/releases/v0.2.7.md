# Personal Agent v0.2.7 Release Notes

v0.2.7 completes Work Package 1: unified conversation understanding and
capability routing.

## Conversation routing

- One typed, offline request-understanding result now owns ordinary `/chat`
  capability selection.
- Eleven implemented native conversation capabilities are selected through a
  live, schema-validated capability registry.
- Registry invocation receives validated structured inputs and calls native
  implementations directly; legacy phrase classifiers cannot reclassify a
  selected capability.
- Ambiguous goals ask one concise question, while approval, denial, and
  cancellation remain deterministic and thread-bound.
- Presence, capability, identity, and runtime claims are grounded in live
  service state, with a response guard for contradictory generated claims.

## Compatibility and safety

- Existing filesystem, system information, model management, Model Scout,
  text-pack, conversation-history, Web UI, and local-model behavior is
  preserved.
- No executable packs, automated pack acquisition, or general plan/act/verify
  loop is introduced by this release.
- The core semantic matcher remains local and does not add a required cloud
  dependency or a second ordinary model generation.

## Verification

- The canonical release gate now includes the unified production-path routing,
  held-out language, transformation, multi-turn, false-runtime-claim, and
  safety-boundary suite.
- Promotion is permitted only from the exact tested commit after isolated API
  and Web UI verification.
