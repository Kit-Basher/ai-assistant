# Personal Agent v0.2.18

This is the final Work Package 4.5 candidate. It contains the model-runtime
truth, installed-model evaluation, canonical Scout/Manager presentation, and
deterministic response-latency closure introduced in v0.2.17.

The release additionally closes a live-verification finding: a human-spaced
provider-native identity such as a model family followed by its size now
resolves against the canonical live inventory for test/switch previews. The
resolution is derived from installed canonical IDs; it is not a model-name or
request-phrase trigger table. Selection still uses the unified capability
router, and testing or switching remains bound to the existing exact preview
and confirmation authority.

No model was downloaded, deleted, tested through a live mutation, or switched
while producing this release. The default remains `ollama:Gemma:latest` unless
the user separately confirms the exact evidence-backed recommendation.
